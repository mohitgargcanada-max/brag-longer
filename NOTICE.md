# Credits

**Brag Longer** (`/brag-longer`) was created by **Mohit Garg** (ScaleQor).

It is inspired by **/brag** and **/brag-slim** by **Shunit Haviv Hakimi**:
https://github.com/latent-spaces/brag (MIT License, Copyright (c) 2026 Shunit Haviv Hakimi).

/brag-longer contains no code or assets from /brag. It follows /brag's approach to launch videos (story first, show the
real product, frames built in a browser as a pure function of time, a settled poster frame) and extends it to
multi-minute narrated films. Thank you to the original author for the idea and the craft it set out.

Third-party components used at run time (installed separately, with the person's consent):
- Kokoro-82M voice model, Apache 2.0: https://huggingface.co/hexgrad/Kokoro-82M
- kokoro-onnx, MIT: https://github.com/thewh1teagle/kokoro-onnx
- FFmpeg via imageio-ffmpeg; Playwright (Apache 2.0) with Chromium.
